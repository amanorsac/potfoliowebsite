Questions, answered.

Is this a DAW?
No. There is no arrangement timeline, no plugin hosting, and no mixing suite. PerformLive is for performing finished material. Most users produce in a DAW and perform in PerformLive.
Will it change my audio files?
No. Files are read, never modified. Tempo is detected and displayed but not applied. Time-stretching happens only if you explicitly set a row tempo or engage LOCK.
What formats does it read?
WAV, AIFF, FLAC, MP3, and OGG.
Does it work with a touchscreen?
Yes, that is the primary design target. It also works fine with a mouse and keyboard.
Can I use a MIDI controller or foot pedal?
Yes. Row triggers, pads, and FX slots can each be bound via MIDI Learn.
Can I send different stems to different outputs?
Yes. Each mixer channel has an output route for multi-output interfaces.
What happens if it crashes mid-set?
Autosave runs every minute; on the next launch you are offered the recovered session. Your project file is separate and untouched.
Is there a Mac version?
Not currently. Windows only.
